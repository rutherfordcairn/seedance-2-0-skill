# Prompt checklist

Describe the subject before the action, then camera, lighting, setting, motion,
audio and exclusions. Repeat identity and wardrobe details in every shot that
uses a reference image. Give each reference one unambiguous role and use the
same role name throughout the prompt. Keep creative intent separate from
transport fields such as model, duration and resolution; the validator owns
those fields so a copied prompt cannot silently change the request contract.
